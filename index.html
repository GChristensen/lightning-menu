Your favorite links, one click away.

Lightning Menu adds a single button to the browser toolbar. Click it, or press its shortcut, and a compact menu of your links drops down. Pick one and it opens in a new tab.

A launcher, not another bookmarks bar

For the sites you visit every day and the internal tools whose address you never remember.

Your links, your order

Add links, title them, group them with separators. Reorder by dragging, or drop a link from any page or the address bar onto the settings page.

An icon for every link

Find the site's icon automatically, point to any image URL, or upload a file. Uploads are stored in your settings and work offline.

Make the button yours

Change the toolbar button's title and icon. The menu follows the system theme, or stays light or dark.

Several menus

One for work, one for home. Install Lightning Menu 2, 3 and on, each with its own button, links, icon and shortcut.

Get extra copies from GitHub Releases

Private by design

No accounts, no tracking, no data collection. Access to websites is requested only when you ask it to find a site icon.

Import and export

Back up your menu to a JSON file and restore it in another browser. Settings from MultiButton menus import too.

Never reach for the mouse

Open the menu with a shortcut, then press a link's access key to go straight to it. Links are numbered 1–9, then a–z.

Change the shortcut in your browser's extension shortcut settings.
